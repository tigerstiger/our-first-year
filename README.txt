OUR FIRST YEAR — v3 (autoplay attempt)

- Extract the ZIP, then place your legally usable music file at:
  assets/the-bones.mp3
- Open index.html to preview.
- The page now attempts to start audio as soon as it loads.
- Browsers often block audible autoplay, especially on iPhone Safari.
  If blocked, the visitor must tap PLAY OUR STORY once. This is a browser
  restriction and cannot be reliably bypassed by website code.
- The site is not published online. Upload the complete extracted contents
  to a static host to get a URL, then write that URL to the NFC tag.
- The video is intentionally omitted and can be added later.
